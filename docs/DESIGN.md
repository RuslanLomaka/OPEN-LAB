# Design system

Design direction: experimental technology magazine crossed with a hacker's control panel. Inspiration: editorial brutalism, oversized expressive typography and high-contrast utilitarian layouts. This is an original interface, not a direct copy.

- Background: warm paper `#f3f0e8`; ink `#191919`; accent orange `#ff5830`.
- Black rules, sharp edges, monospace labels, compact cards, prominent CTAs.
- Big typographic hero, orbital AI graphic, category filters, cards, modal tool instructions, workflow recipes.
- Responsive mobile layout, keyboard-operable controls, favorites saved in localStorage.
- Accessibility and trust should take priority over novelty.
