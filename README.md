# OPEN//LAB

**Stay curious. Pay less.** An experimental, editorial-style directory of AI tools, trials and workflows.

## Live site
After enabling GitHub Pages at **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**, the expected address is `https://ruslanlomaka.github.io/OPEN-LAB/`.

## Local preview
Clone the repository and open `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Structure
- `index.html`: entry point for GitHub Pages
- `style.css`: responsive visual design
- `app.js`: sample tool records, search, filters, favorites and workflows
- `docs/PROJECT_VISION.md`: concept and audience
- `docs/DESIGN.md`: visual direction
- `docs/ROADMAP.md`: implementation plan
- `docs/AI_RESEARCH.md`: official research starting points

## Status and limitations
**Prototype only.** This site uses static illustrative listings; it does not automatically verify whether any offer remains available. Always check official providers' pricing, eligibility, regional restrictions and billing terms. Favorites are stored only in the current browser's localStorage.

The public repository intentionally excludes private conversation archives. Keep exports and private notes off the public GitHub Pages branch.
